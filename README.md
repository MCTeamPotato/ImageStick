# ImageStick 插件介绍

ImageStick 是 [ImageFrame](https://modrinth.com/plugin/imageframe) 的拓展，用于简化在 Minecraft 中播放幻灯片的流程。

你可以把一组图片展示在由物品展示框组成的"屏幕"上，然后手持木棍点击屏幕来翻页——就像在现实中用遥控器翻 PPT 一样。

---

## 使用流程

### 第一步：准备图片

将你的图片（支持 PNG、JPG、JPEG、GIF、WEBP 格式）放入服务器的以下目录：

```
plugins/ImageStick/images/<你的目录名>/
```

例如，想展示一组名为 `presentation` 的幻灯片，就把图片放进 `plugins/ImageStick/images/presentation/`。

图片会按文件名末尾的数字排序（如 `slide1.png`、`slide2.png`……），请提前命好名。

---

### 第二步：导入图片

在游戏中执行：

```
/imagestick import <目录名> <宽度> <高度>
```

- **宽度 / 高度**：屏幕由几列 × 几行物品展示框组成。例如 2×2 的屏幕就填 `2 2`。

示例：
```
/imagestick import presentation 2 2
```

插件会自动逐张调用 ImageFrame 将图片导入为地图，并在聊天栏显示进度。

---

### 第三步：搭建屏幕

在墙上放好对应数量的物品展示框（例如 2×2 就需要 4 个）。展示框必须相邻且朝向一致。

---

### 第四步：绑定屏幕

**看向屏幕左上角的展示框**，然后执行：

```
/imagestick bind <目录名> <宽度> <高度>
```

示例：
```
/imagestick bind presentation 2 2
```

绑定成功后，屏幕会自动显示第一张幻灯片。

---

## 日常使用

绑定完成后，任何有权限的玩家只需：

| 操作                    | 效果            |
|-----------------------|---------------|
| **手持木棍，右键**点击屏幕上任意展示框 | 切换到**下一张**幻灯片 |
| **手持木棍，Shift + 右键**点击 | 切换到**上一张**幻灯片 |

聊天栏会显示当前进度，例如：`Slide 3 / 8`。

---

## 注意事项

- 执行 `/imagestick import` **必须由玩家**在游戏内操作，控制台无法使用。
- 导入前请确保服务器能访问到图片（插件内置了 HTTP 文件服务器，管理员需确保对应端口已开放）。
- 如果拆掉了屏幕上的任意一个展示框，该组幻灯片的绑定会**自动解除**，需要重新绑定。
- 幻灯片数据在重启后会自动保留，无需重新绑定。

---

## 命令一览

| 命令                                | 说明                    |
|-----------------------------------|-----------------------|
| `/imagestick import <目录> <宽> <高>` | 批量导入图片为 ImageFrame 地图 |
| `/imagestick bind <目录> <宽> <高>`   | 将屏幕与图片组绑定             |
| `/imagestick reload`              | 重载配置文件                |

所有命令需要 `imagestick.use` 权限（默认仅 OP）。
